# GeauxTravel frontend

This is the React and TypeScript starting point for the website. The page is a placeholder while the team adds the real trip planning features.

## Run it

Use Node.js 20.19+ or 22.12+.

```sh
cd frontend
npm install
npm run dev
```

Open the local address printed by Vite. To check the frontend before making a PR:

```sh
npm run lint
npm run build
```

The Java work is still in the repository root and is separate from this frontend folder.
