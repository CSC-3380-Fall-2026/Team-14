# GeauxTravel first wireframes

[View the wireframes](GeauxTravel%20Design%20Draft.pdf)

For [Sketch Website and Wireframe #14](https://github.com/CSC-3380-Fall-2026/Team-14/issues/14).

The flow starts with choosing a destination, then setting dates, budget and activity level, viewing an itinerary and saving the trip.

The PDF includes the flow and eight screen designs: Home, Destination, Trip preferences, Itinerary, Compare flights, Sign in, My trips and Leave a review. Each screen has a desktop and phone layout.

The cream background and light purple buttons stay the same throughout. Photo and map credits are included in the PDF.
